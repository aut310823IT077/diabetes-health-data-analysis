# Diabetes Health Indicators Analysis

## Project Overview

This project explores the relationship between diabetes status and selected health indicators using Python, SQL, and data visualization. The analysis uses survey data to identify patterns related to high blood pressure, BMI, physical activity, age category, and general health.

## Objectives

* Analyze the distribution of diabetes status in the dataset.
* Examine the relationship between high blood pressure and diabetes status.
* Compare average BMI between diabetes groups.
* Explore physical activity and general health patterns.
* Study how diabetes prevalence varies across age categories.
* Practice data analysis using Python and SQL.

## Dataset

**Dataset:** Diabetes Health Indicators Dataset (BRFSS 2015)

**Source:** [Kaggle – Diabetes Health Indicators Dataset](https://www.kaggle.com/datasets/alexteboul/diabetes-health-indicators-dataset)

The dataset contains health-related indicators collected through the Behavioral Risk Factor Surveillance System (BRFSS).

## Project Workflow

1. Load and inspect the dataset.
2. Check data types, missing values, and duplicate records.
3. Prepare a cleaned analysis dataset.
4. Load the data into an SQLite database.
5. Perform SQL queries to summarize health indicators.
6. Compare diabetes status with selected health indicators.
7. Visualize the results using charts.
8. Document the analysis and findings.

## Key Analysis Areas

* Diabetes status distribution

* Average BMI by diabetes status

## Limitations

* The dataset is based on survey responses and may contain self-reported information.
* The analysis identifies associations, not causal relationships.
* Age is represented by coded age categories rather than exact ages.
* Duplicate rows were removed in the analysis copy; this may affect counts and should be considered when interpreting results.
* The findings should not be used for individual medical diagnosis.
